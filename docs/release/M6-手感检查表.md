# M6 手感检查表

## 使用方式

在发布前先运行自动门禁，再用 `dist/win-unpacked/FreeLinkBoard.exe` 做人工手感检查。人工检查时建议使用新的空白白板和一个临时 `.flb` 文件，完成后删除临时文件。

自动门禁：

```powershell
npm.cmd run release:check
git diff --check
```

## 人工验收清单

- [ ] 双击画布空白处可以创建文本节点，节点进入可编辑状态，输入内容后按 `Esc` 可退出编辑。
- [ ] 选中文本节点后连续按 `Tab` 可以创建并跳转到下一个关联节点，连续链路方向和节点位置自然。
- [ ] 选中一个节点后按 `Ctrl+L` 进入连线流程，点击目标节点后生成连线，取消流程不会留下半成品连线。
- [ ] 连线固定点命中稳定：鼠标靠近连线端点或控制点时可选中，拖动后连线仍连接正确节点。
- [ ] 框选多个节点后可以一起拖动；拖动后 `Ctrl+Z`/`Ctrl+Y` 可以撤销和重做位置变化。
- [ ] 搜索可高亮命中节点；切换上一个/下一个结果时视口会把目标节点移动到可见区域。
- [ ] 保存当前白板为 `.flb`，关闭应用后重新打开，最近文件列表能打开该文件且节点、连线、视口内容保持一致。
- [ ] 打开大白板或快速缩放/平移时，节点裁剪没有明显卡死、白屏或整页 DOM 暴涨的体感问题。
- [ ] 搜索设置、主题或外观设置在关闭后重新打开仍能保留。

## 已知发布风险

- Windows unpacked 包尚未配置正式应用图标。
- `package.json` 尚未填写 `author`，Electron Builder 会提示非阻塞警告。
- 当前 ESM preload 依赖 `sandbox: false`；如果未来重新启用 sandbox，需要先调整 preload 构建形态。
- 本检查表不覆盖云同步、图片/PDF/URL 节点、插件系统、多人协作或 `.flb` 附件包格式，这些不属于 M6 范围。
