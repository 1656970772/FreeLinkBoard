# 搜索面板默认隐藏修复记录

## 用户要求

- 白板搜索面板默认隐藏。
- 只有按 `Ctrl+F` 时才显示搜索面板。

## 实现

- `BoardPage` 在进入或切换白板时关闭旧的搜索打开状态，避免上一次会话留下的搜索面板常驻。
- 搜索面板关闭时不再计算搜索结果，也不再向节点层传入搜索高亮，避免隐藏搜索条后画布仍保留搜索态。
- `Ctrl+F` 仍通过 `BoardCanvas` 的键盘快捷键打开搜索面板，并保留已有查询词。
- E2E teardown 改为销毁测试窗口后退出 Electron，绕开脏白板的 `beforeunload` 用户确认路径，避免测试退出不稳定。
