# 2026-05-15 FreeLinkBoard M3b 框选与固定尺寸开发记录

## 背景

- 本轮继续推进 M3 文本节点交互，目标是补齐 M3a 留下的 M3b 范围：框选、多选整体移动、手动 resize 后进入固定尺寸。
- 主要来源：`docs/superpowers/specs/2026-05-14-freelinkboard-design.html`、`docs/superpowers/plans/2026-05-15-freelinkboard-m3-text-node-interactions-plan.md`、`docs/superpowers/plans/2026-05-15-freelinkboard-m3b-selection-resize-plan.md`、`Memory/2026-05-15_14-40-00_M3文本节点交互.md`。

## 实现内容

- 新增 M3b 实施计划：`docs/superpowers/plans/2026-05-15-freelinkboard-m3b-selection-resize-plan.md`。
- `BoardCanvas` 新增空白左键框选状态机，框选结束后按世界坐标选中与矩形相交的节点。
- `InteractionOverlayLayer` 新增 `selection-box` 叠层，用于显示框选矩形。
- 多选拖动继续复用 `MoveNodesCommand`，并补了拖动后吞掉补发 click 的保护，避免多选被折叠成单选。
- 新增 `ResizeNodeCommand`，resize 节点时写入 `size`、切到 `sizing: "fixed"`、支持 undo/redo。
- `UpdateTextNodeCommand` 区分 auto/fixed：auto 继续按文本估算高度，fixed 编辑文字时保持尺寸不变。
- `NodeDomLayer` 为选中且非编辑态的节点显示右下角 resize handle；节点 DOM 改为 `boxSizing: "border-box"`，使 `node.size` 与可见外框一致。
- `HistoryService` 和 `documentStore` 增加 no-op command 防护，避免 missing-node 命令污染 history、saveStatus 或 redo 栈。
- `.flb` codec 新增 fixed-size 节点 round-trip 回归测试。

## Review 修复

- P2：多选拖动后真实浏览器可能补发 click，导致 `onNodeClick` 把多选折叠成单选。已用测试模拟补发 click，并通过 `suppressNextNodeClickRef` 修复。
- P2：节点 DOM 默认 content-box 与 `node.size` 的几何含义不一致，且 resize handle 可能被 `overflow: hidden` 裁掉。已改为 `boxSizing: "border-box"` 和 `overflow: "visible"`，让 fixed size、框选命中和 handle 位置一致。
