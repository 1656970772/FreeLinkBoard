# M6 Windows 打包记录

## 本次结论

- 已为 FreeLinkBoard 增加 Windows unpacked 打包入口：`npm run package:win`。
- 已新增 `electron-builder.yml`，打包 `out/**`、`package.json` 与生产运行时依赖，并排除 `Memory/**`、`docs/**`、`tests/**`、`test-results/**`、`logs/**`、`.worktrees/**`、`worktrees/**`、`NUL.heapsnapshot` 与日志文件。
