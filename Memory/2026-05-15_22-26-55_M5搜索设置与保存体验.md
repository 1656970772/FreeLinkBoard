## 已完成内容

### 搜索体验

- 新增 `src/application/search/boardSearch.ts`，提供纯函数 `searchTextNodes(board, query)`。
- 新增 `src/renderer/stores/searchStore.ts`，管理搜索面板打开、查询词、结果索引和聚焦请求。
- `BoardPage` 增加搜索面板、结果计数、Previous / Next / Close。
- `BoardCanvas` 支持搜索高亮节点和 active result 定位。
- `NodeDomLayer` 增加 `data-search-highlight` 和视觉高亮。
- `Ctrl+F` 会打开搜索并聚焦搜索框。

### 设置体验

- 新增 `src/renderer/stores/settingsStore.ts`。
- 支持滚轮缩放模式：
  - `ctrlWheel`
  - `directWheel`
- 支持默认连线颜色与宽度设置。
- 设置持久化到 localStorage，并对持久化数据做合法性校验与宽度 clamp。
- 新建连线和连线预览会使用默认连线样式。

### 删除、复制、粘贴与历史

- `boardInteractionCommands.ts` 新增：
  - `DeleteBoardItemsCommand`
  - `PasteBoardItemsCommand`
- `CreateEdgeCommand` 和 `CreateLinkedTextNodeCommand` 支持传入默认连线样式。
- `documentStore` 增加：
  - `copySelection`
  - `deleteSelection`
  - `pasteClipboard`
- 删除、粘贴都走 undoable command/history。
- 复制选中节点时会包含 incident edges，并在粘贴时重映射已复制节点端点。

### 保存与关闭体验

- `documentStore` 增加 `saveCurrentBoardNow()`。
- 命名画布支持 700ms debounce 自动保存。
- `Ctrl+S` 和 BoardPage Save 按钮会保存当前画布。
- 未命名画布保存会走 Electron Save As：
  - 新增 `saveFlbAs` shared API。
  - preload 暴露 `flb:save-as`。
  - main 侧新增保存对话框。
  - Save As 路径无扩展时自动补 `.flb`，错误扩展仍拒绝。
- 保存请求期间如果 board 又发生变化，保存完成不会把状态错误覆盖成 `saved`，而是保持 `dirty` 并重新排 autosave。
- `App` 增加 `beforeunload` dirty / unsaved / saving 关闭提示。

### 最近文件体验

- HomePage 显示 `fileError` alert。
- 最近文件项拆成打开按钮和移除按钮。
- 移除最近文件调用 `documentStore.removeRecentFile(path)`，不会触发打开。

## Review 反馈与处理

第一轮 reviewer 提出 3 个 Important：

1. 保存竞态可能把新修改误标为 saved。
2. `Ctrl+F` 没有聚焦搜索框。
3. 复制节点没有包含 incident edges。

已全部修复并补测试。

第二轮 reviewer 复核前三项已修复，同时指出 Save As handler 尚未接入无扩展路径 normalize。随后修复：

- `flb:open-dialog` / `flb:load` 使用 `assertFlbPath`。
- `flb:save-as` 使用 `normalizeFlbSavePath`。
