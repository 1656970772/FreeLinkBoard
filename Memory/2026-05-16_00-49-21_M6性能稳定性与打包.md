# M6 性能稳定性与打包收尾记录

## 已实现范围

- 大图性能指标：新增 5,000 节点、8,000 连线 fixture 的规模、裁剪、空间索引和边路径缓存指标。
- 大图渲染 smoke：验证大白板渲染时 DOM 只挂载视口内节点，避免退化为全量节点渲染。
- 大文件保存稳定性：覆盖 5,000 节点、8,000 连线 `.flb` 保存再读取、失败清理、临时文件唯一性和长文件名场景。
- Electron E2E：使用 Playwright 启动真实 Electron，覆盖隔离用户数据目录、新建白板、创建文本节点和搜索命中流程。
- Windows 打包：新增 Electron Builder 配置和 `package:win`，生成 `dist/win-unpacked/FreeLinkBoard.exe`。
- 发布门禁：新增 `release:check`，串联类型检查、单测、构建、大图性能、E2E 和 Windows 打包。
- 发布文档：新增 `docs/release/M6-手感检查表.md`，用于发布前人工检查核心手感路径。

## 剩余风险

- 仍需人工执行 `docs/release/M6-手感检查表.md`，自动测试不能完全替代拖拽、缩放、搜索居中和保存重开手感。
- Electron Builder 仍提示 `author is missed in the package.json`，不阻塞打包。
- 当前使用默认 Electron 图标，后续发布正式版本前应补应用图标。
- 当前 ESM preload 依赖 `sandbox: false`，未来若恢复 preload sandbox 需要先改构建形态。
